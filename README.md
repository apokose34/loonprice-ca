# LoonPrice (Canada Price Comparison Platform)

1. Update `config.js` with your Supabase `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY`.
2. Upload this folder to a GitHub repository.
3. Add `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` under **GitHub Repo -> Settings -> Secrets and variables -> Actions**.
4. Import the GitHub repository into **Vercel** and deploy!
